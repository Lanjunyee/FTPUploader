FTP 文件传输技术支持

适用于 macOS 15 及以上版本。支持 FTP、FTPS、SFTP 服务器连接与文件、目录上传下载。

开始使用

  1. 在站点管理中添加服务器，选择协议并填写服务器地址、端口和认证信息。
  2. 连接服务器；根据提示核对 FTPS 证书或 SFTP 主机密钥。
  3. 通过系统文件选择器授权访问本地文件或目录。
  4. 浏览远程目录并上传或下载。目录传输前请核对传输计划和同名文件处理策略。
  5. 在队列与记录窗口查看传输结果。

常见问题

无法连接时，请检查服务器地址、端口、网络及账号权限。本应用不提供服务器账号。文件访问失败时，请重新使用系统选择器授权。遇到证书或主机密钥变更时，请先向服务器管理员核实，勿直接忽略安全警告。普通 FTP 不加密，建议使用 FTPS 或 SFTP。

联系支持

请在GitHub Issues提交问题，并说明 macOS 版本、应用版本、协议类型、操作步骤和已脱敏的错误信息。该渠道公开可见，需 GitHub 账号。

请勿提交密码、私钥、完整服务器地址、真实账号、私人文件或未经脱敏的截图与日志。
