# FTPUploader 0.3.0 — Release 说明草稿

**尚未发布，不代表正式发行就绪。** 以下能力属于 0.3.0 源码及本地候选，不属于已有 v0.2.0 安装包。

## 新增与改进

- 紧凑原生工作台：可折叠站点栏、对等上传／下载入口、名称／大小目录列及按需展开的完整信息。
- 当前已加载目录本地文件名筛选：不新增网络请求，支持 Unicode 规范等价和不区分大小写的字面匹配；隐藏项目退出选择，清词不会重新选中。
- 文件夹和混合选择的双向传输：保留相对结构与空目录，扫描预览后明确开始，支持失败依赖与独立显式重试。
- 双向摘要与完整队列：覆盖、最终确认、部分结果、取消等待及清理警告不因精简隐藏。
- SFTP 本地私钥认证、加密口令及只读文件关联；口令不持久保存，不自动信任变化的主机。
- 浅／深色外观跟随系统强调色，改进窄窗口和必要文字可读性。

## 系统与包格式

最低 **macOS 15**，不再支持 macOS 13／14。候选包含 Apple Silicon（arm64）和 Intel（x86_64）架构，内置静态依赖及 libssh2／OpenSSL 许可证。

本地候选名称含 `local-candidate`，约 8 MiB；本地 app 版本 0.3.0，构建号 3。SHA256SUMS 用于校验最终对应 ZIP，重新签名或装订票据后必须重新生成。

## 已完成本机检查

公开工作台源码在 macOS 27.0.1 / Apple Silicon 上 arm64 与 Rosetta 各 294 项回归通过。候选通用 Release 构建、版本／最低系统、sandbox／权限／链接、许可证、Hardened Runtime 本地 flag、严格 ad-hoc 签名、ZIP 解压一致性及本地非隔离启动通过。

## 发布前仍需完成

- Developer ID Application 正式签名、可信时间戳及签名运行验证。
- Apple 公证 Accepted、票据装订、最终包验证及隔离下载首次运行。
- 实际 macOS 15 和 Intel 硬件验证；目前没有这些设备。

**当前本地候选未 Developer ID 签名、未公证，不应作为“已全部验证”的正式版本发布。** 本地 Hardened Runtime、Rosetta 或编译成功不替代上述门槛。详见 [候选检查清单](release-0.3.0.md)。

普通 FTP 不加密。覆盖检查与写入不是条件原子操作；取消／失败保留已成功内容，不保证整目录原子完成，不自动删除或重试。不支持续传、远程删除／改名／权限管理。
