# FTPUploader 0.3.0 — 预发布

**这是未公证的预发布版本，适合愿意接受以下限制的用户测试。** 使用本地 ad-hoc 签名，未使用 Developer ID Application 证书，未经过 Apple 公证。首次打开可能被 macOS 拦截；本地签名检查通过不代表 Apple 已验证或信任此应用。

## 新增与改进

- **紧凑原生工作台**：可折叠站点栏、对等上传／下载入口、名称／大小目录列，完整位置与文件信息按需展开。
- **当前目录筛选**：仅匹配已加载文件名，不增加请求；支持 Unicode 规范等价及不区分大小写的字面匹配。隐藏项目退出选择，清词不会重新选中。
- **文件夹双向传输**：文件夹与混合选择先扫描预览、明确开始，保留相对结构和空目录；失败依赖与显式重试分别呈现。
- **双向摘要与完整队列**：覆盖、等待最终确认、部分结果、取消资源等待和清理警告保持可见。
- **SFTP 私钥登录**：本地私钥、加密口令及只读文件关联；口令不持久保存，不自动信任变化的主机。
- **系统外观适配**：浅／深色、系统强调色及窄窗口可读性改进。

## 下载与安装

最低 **macOS 15**，不再支持 macOS 13／14。应用版本 0.3.0，构建号 3。

下载 `FTPUploader-0.3.0-macOS-universal.zip`，核对 `SHA256SUMS.txt`，解压后将 `FTPUploader.app` 放入“应用程序”文件夹。包包含 Apple Silicon（arm64）与 Intel（x86_64），内置静态依赖及 libssh2／OpenSSL 许可证，运行无需安装开发工具。

```sh
shasum -a 256 -c SHA256SUMS.txt
```

仅在确认来源与校验和可信后考虑运行。如果 macOS 阻止打开，可查看“系统设置 → 隐私与安全性”中针对该应用的提示；系统是否允许继续取决于实际提示与策略。**不建议关闭 Gatekeeper、绕过安全检查或忽略恶意软件告警。**

## 已完成验证

- 公开工作台源码在 macOS 27.0.1 / Apple Silicon 上 arm64 与 Rosetta 各 **294 项测试通过**。
- 0.3.0 候选通用 Release 构建、版本、两架构最低系统声明、sandbox、权限、系统链接与许可证检查通过。
- 保留 Hardened Runtime，本地 ad-hoc 签名严格检查通过，Release 无 get-task-allow 调试权限。
- ZIP 校验、解压后签名与主程序一致性，以及本地非隔离启动检查通过。

## 已知限制

- **未 Developer ID 签名、未公证**；没有验证最终下载包的隔离首启。预发布不是正式可信分发声明。
- **实际 macOS 15 与 Intel 真机尚未验证**；编译与 Rosetta 不替代实机。
- 普通 FTP 不加密。FTPS 严格验证证书，SFTP 首次连接需独立核对主机指纹。
- 不保证整目录原子完成；失败／取消保留已成功内容，不自动删除、回滚或重试。
- 检查与写入不是条件原子操作，仍有非合作并发竞态。不支持续传、远程删除／改名／权限管理。

本版本保留原有授权与安全守卫，不更改 macOS 系统安全偏好。旧 v0.2.0 稳定 Release 与安装包不覆盖、不删除。
