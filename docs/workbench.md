# 紧凑工作台指南

本文对应当前源码，不代表已发布的 v0.2.0 安装包。新工作台最低 macOS 15；实际最低系统及 Intel 硬件运行证据仍缺失。

## 站点与目录

左侧站点栏用序号与短名区分站点，可滚动、收起；收起后“连接与位置”和“更多”仍提供站点选择、手动连接与管理入口。选择、保存、取消站点配置不会自动连接；传输忙碌时不能修改有效身份和目标。

“连接与位置”展开显示实际有效协议、身份与完整位置，可复制；编辑中的待连接地址不是有效连接。FTP 的忙碌锁不表示加密。

目录默认名称／大小列，大小右对齐，列宽可调整。“目录显示”可开启类型列并按名称、类型、大小排序。类型来自服务器真实分类，不按扩展名推断。链接、特殊和未知类型不作为普通文件传输。

单击选择，双击唯一文件夹进入；普通文件双击不下载。右键、所选项目更多菜单及已有快捷键共用动作。文件信息展示完整原名、类型、已知大小与位置，查看或复制不查询额外元数据。

## 本地文件名筛选

筛选只处理当前已加载的完整名称，包括文件夹，不递归、不刷新、不新增请求。匹配采用 Unicode 规范等价、不区分大小写的字面子串；空格、`%`、`#`、`*`、`?` 均按字面处理，不是通配符。

界面区分空目录、没有匹配、读取中和读取失败，并显示可见／总项数。隐藏项目退出选择；**清除筛选不会重新选中它们**。下载只针对实际选中的可见项目，不包含其他未选中的匹配项。

Return 不开始连接或下载；已有 Escape 行为先清词，再收起，不取消实际传输。成功导航或身份变化清词；同目录刷新保留词并重新计算，导航失败保留原筛选并单独显示错误。重新打开不恢复词或选择。

下载选择器捕获的选择失效后，返回不开始扫描或下载，须重新发起。已确认计划及正在执行的任务不会因筛选、排序或详情而修改来源、目标或结果。

## 上传与下载

“选择单个文件…”只选择，须独立点击开始；文件夹或混合选择只扫描和预览，确认前不发送内容、不创建目录。单个普通文件拖入只选择；其他拖放进入预览。取消选择器、扫描或预览不开始写入。

普通文件下载使用系统保存界面；文件夹或多选先选择保存根并核对计划。保留所选文件夹本身名称、嵌套结构和空目录。普通目录只合并，不删除额外内容或复制权限。类型冲突、可识别链接、不可读项、重叠根、重复目标、编码问题或超限阻止开始，不静默忽略或改名。计划最多 10,000 节点、深度 64。

FTP 列表保留服务器名称原始字节，支持 UTF-8／GB18030；SFTP 使用严格 UTF-8。FTP 服务端可能不暴露链接身份，因此不承诺远程 no-follow。

同名普通文件默认逐项询问，Return 默认取消；仅本计划的显式跳过／覆盖策略不继承至新计划或重试。下载目标变化需独立确认；检查与替换不是服务端条件原子操作。

## 摘要与队列

主窗口摘要优先显示真实扫描、执行、覆盖或取消上下文，其次待处理批次、待上传文件、最近结果。旧结果保留原目标，不冒充当前目录的结果；目标不同会提供分别核对入口。没有选择、任务或结果时不显示空条。

字节收齐仍须等待服务器最终确认，下载还需本地安全提交。未知大小和目录任务不伪造字节百分比；成功字节与包含失败、取消、重试的实际流量分别统计。失败、部分结果、覆盖待决、取消资源等待及清理警告直接显示，不能只藏在详情内。

关闭队列或详情不会取消传输。取消当前与取消全部作用不同；后端与授权释放前仍锁定。失败暂停后须明确处理：跳过、核对失败项重试预览或继续。重试是新计划、新覆盖决定，原失败和新结果独立保留，不自动重传。父目录失败／跳过会阻塞后代，依赖原因在队列显示。

下载内容先写入同卷随机临时文件，协议确认与本地关闭成功后提交。失败或取消保留原目标；只清理本次创建的临时内容。清理失败显示位置，不删除未知内容。突然退出后的残留需确认无活动下载后手动处理。

## 隐私与交互政策

最近 100 条本机终态记录包含文件名、服务器与路径，不含密码、私钥、口令、书签或可恢复任务。当前会话完整队列不受历史上限裁剪。损坏历史保留，加载或写入失败不改变实际传输结果。清除历史不删除文件或站点，重启不恢复队列。

现有及后续页面保留普通可读性、可点击入口与业务安全要求。声音／VoiceOver、仅键盘完整流程、焦点顺序及焦点恢复不是强制开发或验收门槛；已有快捷键和原生默认行为可以保留，不能绕过明确开始、校验、覆盖决策或忙碌守卫。
