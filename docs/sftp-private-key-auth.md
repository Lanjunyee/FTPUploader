# SFTP 私钥登录

选择 SFTP（SSH）和“私钥文件”，输入服务器地址、用户名，通过“选择私钥…”选择普通私钥文件。系统选择器可显示隐藏目录；应用不会扫描 `~/.ssh`，不复制或修改源私钥。选择文件、取消选择、选择站点和保存站点均不会自动连接。

加密私钥需输入私钥口令，未加密私钥留空。口令遮蔽显示，保留空格、Unicode 和符号，拒绝空字符。口令仅属于当前连接会话，不保存到站点、钥匙串、记录或日志；身份、认证方式、私钥变化、认证失败及退出后需重新输入。没有“记住口令”。密码认证原有的钥匙串和显式空密码功能继续适用。

## 支持范围

固定 libssh2 1.11.1 / OpenSSL 3.5.9 下，以下格式均以临时本机服务器完成目录、二进制上传和下载验证。加密用例使用包含中文、空格和符号的口令，不需要独立公钥文件；测试没有放宽服务器 RSA-SHA2 设置。

| 格式 | 未加密 | 口令加密 |
|---|---|---|
| OpenSSH Ed25519 | 通过 | 通过 |
| OpenSSH RSA | 通过 | 通过 |
| PEM PKCS#1 RSA | 通过 | 通过 |
| PEM PKCS#8 RSA | 通过 | 通过 |

不支持仅公钥文件、SSH 证书、硬件密钥、其他密钥类型、SSH agent、跳板机和自动格式转换。文件必须为非空、可读且不超过 1 MiB 的普通文件。

## 文件关联和连接快照

手动选择仅在本次应用运行保留。保存站点仅保存只读安全书签、显示名称和已确认内容摘要；重启恢复关联后仍需自行输入口令。取消编辑不会持久保存关联，删除站点不删除源文件。

每次新连接重新读取已授权文件并核对摘要。文件内容被替换、授权失效、文件丢失或无法访问时，连接前直接提示“重新选择”，清除旧口令，不静默接受新密钥。完整文件路径可在表单中查看和选择文本。

成功连接后的目录、上传、下载及批次使用同一份内存密钥快照，源文件随后替换或删除不会修改已发起的认证上下文。批次暂停期间仍锁定身份、方式、文件及口令；重试重新检查上传目标，覆盖确认只授权本次写入。全部取消或完成释放批次持有的材料，仍被活跃连接使用的快照在连接失效时释放。只读文件授权在每次读取和书签操作后配对结束，不持有开放文件句柄。

## 错误修复

- 无法读取、授权失效、内容变化：重新选择私钥，再输入适用口令。
- 无法解锁或格式不支持（SSH -1010）：检查是否选择私钥、支持格式和正确口令。底层无法可靠区分错误口令与损坏文件，因此合并提示。
- 服务器拒绝公钥（SSH -1011）：核对用户名和服务器 `authorized_keys` 授权。
- 未知或变化的主机指纹：先通过独立可信渠道核对指纹。主机信任校验发生在账户认证之前。
- 超时、取消或网络错误：只有服务器确认和本地下载提交完成后才显示成功。

任何失败都不回退到密码、匿名、其他密钥或 agent。诊断和传输记录不包含私钥字节、口令或书签。此轮仅完善既有文件传输认证，不包含远程命令、文件夹部署或续传。

公开验证范围见 [源码验证记录](source-verification.md)。
